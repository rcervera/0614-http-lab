# 0614-http-lab

# Objectius d'aquest laboratori
    • Entendre què és una petició i una resposta HTTP: mètode, capçaleres, cos i codi d'estat.
    • Conèixer els principals mètodes HTTP (GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, QUERY) i per a què serveix cadascun.
    • Reconèixer els codis d'estat HTTP més habituals (2xx, 3xx, 4xx, 5xx).
    • Fer servir curl per inspeccionar peticions i respostes des de la línia d'ordres.
    • Fer servir les eines de desenvolupador del navegador (DevTools) per observar el mateix trànsit HTTP.
    • Construir una imatge Nginx pròpia amb rutes fetes a mida per practicar cada concepte.
    • Consultar els logs d'accés de Nginx (docker logs) per veure, des del servidor, totes les peticions rebudes.
